Kebijakan Privasi Ludex

Terakhir diperbarui: 30 September 2026

Kebijakan ini menjelaskan bagaimana Jeremy Revaldo ("kami") menangani informasi pada aplikasi Ludex - Katalog Wishlist Game ("Ludex"). Ludex membantu pengguna menjelajahi katalog game, menyimpan wishlist, dan membuat rating serta ulasan.

Informasi yang disimpan Ludex

Ludex menyediakan akun lokal untuk membedakan profil pada satu instalasi aplikasi. Informasi berikut disimpan di penyimpanan aplikasi pada perangkat, bukan pada server Ludex:

  • Nama pengguna akun dan tanggal bergabung.
  • Kata sandi dalam bentuk hash dengan salt; kata sandi asli tidak disimpan.
  • Informasi profil yang pengguna isi, seperti nama pengguna dan bio.
  • Rating, catatan ulasan opsional, wishlist, dan riwayat aktivitas game.
  • ID akun lokal yang digunakan untuk memulihkan sesi masuk.

Data akun disimpan menggunakan IndexedDB dan status sesi menggunakan penyimpanan lokal aplikasi. Kami tidak mengoperasikan server akun dan tidak menyinkronkan data ini ke perangkat lain.

Visibilitas antar akun di perangkat

Untuk fitur komunitas lokal, akun lain yang dibuat pada instalasi Ludex yang sama dapat melihat nama pengguna, bio, rating, catatan ulasan, dan wishlist. Kata sandi, hash kata sandi, dan riwayat pribadi tidak ditampilkan ke akun lain. Data ini tidak dipublikasikan ke pengguna Ludex pada perangkat lain.

Permintaan ke RAWG

Ludex menggunakan RAWG Video Games Database API untuk memuat informasi dan gambar game, pencarian, genre, detail game, serta rekomendasi berdasarkan genre. Saat fitur tersebut digunakan, perangkat mengirim permintaan ke layanan RAWG yang dapat mencakup istilah pencarian, genre atau ID game yang diminta, kunci API aplikasi, alamat IP, dan metadata koneksi standar. RAWG dapat menangani data permintaan sesuai kebijakan dan ketentuannya sendiri. Rating, catatan ulasan, kata sandi, dan data profil lokal tidak dikirim ke RAWG.

Ludex versi ini tidak menggunakan iklan atau SDK analitik dan tidak meminta akses ke lokasi, kontak, kamera, atau mikrofon.

Pembagian data

Kami tidak menjual data pengguna. Data yang disimpan lokal hanya tersedia di instalasi aplikasi tersebut sebagaimana dijelaskan di atas. Informasi permintaan katalog dibagikan kepada RAWG saat aplikasi meminta data game.

Penyimpanan, keamanan, dan penghapusan

Data akun tetap berada di perangkat sampai pengguna menghapus akun melalui Profil > Hapus Akun dan Data, atau sampai data aplikasi dihapus dari pengaturan perangkat maupun aplikasi diuninstal. Penghapusan akun menghapus profil, rating dan ulasan, wishlist, serta riwayat akun tersebut dari database lokal. Data lokal tidak dapat dihapus dari jarak jauh oleh kami karena kami tidak memiliki salinannya di server.

Kata sandi diproses menjadi hash menggunakan PBKDF2 dengan salt. Koneksi ke RAWG menggunakan HTTPS. Penyimpanan lokal aplikasi tidak dienkripsi secara terpisah oleh Ludex; lindungi akses ke perangkat Anda.

Petunjuk penghapusan tersedia di halaman penghapusan akun dan data. Menghapus seluruh data aplikasi dari pengaturan Android akan menghapus semua akun lokal pada instalasi itu.

Privasi anak

Ludex bukan aplikasi yang dirancang khusus untuk anak-anak dan tidak dengan sengaja meminta informasi dari anak-anak.

Perubahan kebijakan

Kami dapat memperbarui kebijakan ini apabila fitur atau praktik data Ludex berubah. Versi terbaru akan dipublikasikan pada halaman ini dengan tanggal pembaruan.
